Executive Summary

The normal backend and frontend app workloads do not need extreme hardware. The expensive part is local AI generation through Ollama. Talvyn creates 3 tests per job description: Technical, Reasoning, and Problem Solving. Each test generation can ask the model to return a structured JSON test with 5 MCQ questions and 2 open-ended questions.

To reach under 2 minutes, the system needs enough GPU memory to keep the model and the parallel request KV cache in VRAM. If the model spills into system RAM, generation speed drops sharply. This is why GPU VRAM is the most important purchasing variable.

How To Read The GPU Format

When choosing the GPU, use the exact model name, VRAM amount, memory type, and cooling/form factor. This avoids buying the wrong class of card.

Correct format Meaning
1x NVIDIA GeForce RTX 5090 32GB GDDR7 Consumer/workstation-style GPU with 32GB VRAM. Good minimum practical local choice.
1x NVIDIA RTX 6000 Ada Generation 48GB GDDR6 ECC Professional active-cooled workstation GPU with ECC memory.
1x NVIDIA L40S 48GB GDDR6 ECC, PCIe, passive cooling Data-center/server GPU. Requires proper rack server airflow.
1x NVIDIA RTX PRO 6000 Blackwell Server Edition 96GB GDDR7 ECC High-end Blackwell server GPU with much more VRAM for future models and concurrency.
1x NVIDIA H100 SXM 80GB HBM3 or 1x NVIDIA H200 141GB Enterprise/cloud AI accelerator class. Best performance, highest cost.

RAM64GB DDR5 minimum.
Storage2TB NVMe Gen4 or Gen5 SSD.
GPU format1x NVIDIA GeForce RTX 5090 32GB GDDR7
Power1000W to 1200W quality PSU.

Why it should be considered: This is the lowest-cost machine I would take seriously for the under-2-minute goal. The 32GB VRAM gives enough headroom for faster local inference than 16GB or 24GB GPUs, and the RTX 5090 has very high compute throughput.

Best use: Local development plus fast generation using gemma3:12b, with OLLAMA_NUM_PARALLEL=3 and TEST_SEQUENTIAL_GENERATION=false.

Caution: This is the minimum practical tier, not the safest one. For gemma3:27b and three parallel generations, 32GB can be tight depending on context length, quantization, and retries.

Configuration Notes For Talvyn

For the under-2-minute goal, the server should run with parallel generation enabled:

  • OLLAMA_NUM_PARALLEL=3
  • OLLAMA_KEEP_ALIVE=-1
  • OLLAMA_FLASH_ATTENTION=1
  • OLLAMA_MAX_LOADED_MODELS=1
  • TEST_SEQUENTIAL_GENERATION=false

The current launcher already sets these ideas by hardware profile. The key difference is that the current detected 4GB GPU forces sequential mode. A 32GB to 48GB+ GPU allows the generation path to run the 3 test requests in parallel.

Hardware I Would Avoid For This Goal

  • 4GB VRAM GPUs: fine for development only. Your current RTX 3050 Laptop GPU is in this category.
  • 8GB to 16GB VRAM GPUs: can run smaller models, but not reliable for sub-2-minute full generation.
  • RTX 4090 24GB GDDR6X: powerful, but still not my first recommendation for the strict target because VRAM is tighter than 32GB/48GB options.
  • CPU-only servers: acceptable for app hosting, but not for fast local AI generation.

Final Recommendation

If you want the best balance of cost, speed, and reliability, choose Option 2: NVIDIA RTX 6000 Ada Generation 48GB GDDR6 ECC workstation. If this will be a real production server in a rack, choose Option 3: NVIDIA L40S 48GB GDDR6 ECC.

If budget is tight and this is mostly for one user or a small team, choose Option 1: RTX 5090 32GB GDDR7. If you want room for much larger future models and more concurrency, choose Option 4: RTX PRO 6000 Blackwell 96GB GDDR7 ECC.
