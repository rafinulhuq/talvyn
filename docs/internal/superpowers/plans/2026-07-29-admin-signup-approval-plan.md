# Admin Signup + Super Admin Approval Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let a company self-register for an admin account via a public `/signup` form, and require a Super Admin to approve the request before that account can log in — no new role tier, no usage caps, no expiry.

**Architecture:** Entirely inside the existing Next.js frontend (App Router + Prisma + NextAuth), following the codebase's existing patterns exactly: the signup form and its endpoint mirror the existing `CreateUserForm`/`admin/users` create flow; the approval action mirrors the existing `UserStatusToggle`/`[id]/status` route; the login gate is one added precondition in the existing `authorize()` callback. No changes to the separate FastAPI backend.

**Tech Stack:** Next.js 16 (App Router), Prisma 6 / PostgreSQL, NextAuth (JWT sessions, Credentials provider), `bcryptjs`, `zod`, Playwright (`tests/e2e`) for testing — this repo has no unit-test runner (jest/vitest), only Playwright e2e.

## Global Constraints

- Approved signups become a plain `ADMIN` — identical capabilities to any admin account created today. Do not add a new role, usage caps, quotas, or expiry.
- No per-company data isolation — confirmed no sensitive data exists in this environment yet. Do not add tenant scoping to JD/candidate/test queries as part of this plan.
- `role` on a signup request is hardcoded server-side to `ADMIN`. Never read `role` or `signupStatus` from the public signup request body.
- Rejected signup requests are kept (`signupStatus: REJECTED`), never deleted, so they can be approved later without the applicant re-registering.
- No email notifications and no CAPTCHA for v1 — the only "notification" is an in-app pending-count badge for Super Admins.
- Every new DB-writing/reading route must reuse the existing `prisma` singleton from `@/lib/prisma`.
- This repo has no seeded test admin / storage-state fixture for e2e (see `frontend/tests/e2e/README.md`). However, this feature is the exception that makes real authenticated e2e testing possible without one: signing up through the real API creates a genuine `ADMIN` account, and a test may flip its `signupStatus` to `APPROVED` directly via `prisma` (simulating what an approval UI does) to then log in through the real `/login` form and get a real authenticated session — no fixture needed. Only the Super-Admin-only surfaces (the approval endpoint's success path, the Users page UI, the sidebar badge) remain untestable in e2e, since there's still no way to become `SUPER_ADMIN` in a test; those are called out explicitly as manual-verification steps rather than skipped silently.

```typescript
// frontend/src/lib/auth/signupRateLimit.ts
/**
 * In-memory IP-keyed rate limit for the public /api/signup endpoint.
 * Same shape as the existing email-keyed loginRateLimit.ts, but keyed by IP
 * since a signup attempt has no existing account to key on yet, and uses a
 * longer window since signup abuse (spam registrations) is a slower attack
 * than credential stuffing.
 */

const MAX_ATTEMPTS = 5;
const WINDOW_MS = 60 * 60 * 1000; // 1 hour
const MAX_TRACKED_KEYS = 5_000;

interface AttemptRecord {
  count: number;
  windowStart: number;
}

const attempts = new Map<string, AttemptRecord>();

function isWindowExpired(record: AttemptRecord): boolean {
  return Date.now() - record.windowStart > WINDOW_MS;
}

export function isSignupRateLimited(key: string): boolean {
  const record = attempts.get(key);
  if (!record) return false;
  if (isWindowExpired(record)) {
    attempts.delete(key);
    return false;
  }
  return record.count >= MAX_ATTEMPTS;
}

export function recordSignupAttempt(key: string): void {
  const existing = attempts.get(key);
  if (!existing || isWindowExpired(existing)) {
    if (attempts.size >= MAX_TRACKED_KEYS) {
      const oldestKey = attempts.keys().next().value;
      if (oldestKey !== undefined) attempts.delete(oldestKey);
    }
    attempts.set(key, { count: 1, windowStart: Date.now() });
    return;
  }
  existing.count += 1;
}
```

```typescript
// frontend/src/app/api/signup/route.ts
import { NextRequest, NextResponse } from "next/server";
import bcrypt from "bcryptjs";
import { z } from "zod";
import { prisma } from "@/lib/prisma";
import { Role, SignupStatus } from "@prisma/client";
import { isSignupRateLimited, recordSignupAttempt } from "@/lib/auth/signupRateLimit";

const signupSchema = z.object({
  companyName: z.string().min(1, "Company name is required").max(255).trim(),
  name: z.string().min(1, "Name is required").max(255).trim(),
  email: z.string().min(1, "Email is required").email("Enter a valid email address").toLowerCase(),
  password: z.string().min(8, "Password must be at least 8 characters"),
});

function clientIp(req: NextRequest): string {
  const forwarded = req.headers.get("x-forwarded-for");
  return forwarded?.split(",")[0]?.trim() || "unknown";
}

export async function POST(req: NextRequest) {
  const ip = clientIp(req);
  if (isSignupRateLimited(ip)) {
    return NextResponse.json(
      { error: { code: "RATE_LIMITED", message: "Too many signup attempts. Please try again later." } },
      { status: 429 }
    );
  }

  const body = await req.json().catch(() => null);
  const parsed = signupSchema.safeParse(body);
  if (!parsed.success) {
    return NextResponse.json(
      {
        error: {
          code: "VALIDATION_ERROR",
          message: parsed.error.issues[0]?.message ?? "Invalid input.",
        },
      },
      { status: 400 }
    );
  }

  recordSignupAttempt(ip);

  const { companyName, name, email, password } = parsed.data;

  const existing = await prisma.user.findUnique({ where: { email } });
  if (existing) {
    return NextResponse.json(
      { error: { code: "EMAIL_TAKEN", message: "An account with this email already exists." } },
      { status: 409 }
    );
  }

  const passwordHash = await bcrypt.hash(password, 12);
  await prisma.user.create({
    data: {
      name,
      email,
      passwordHash,
      companyName,
      role: Role.ADMIN,
      signupStatus: SignupStatus.PENDING,
    },
  });

  return NextResponse.json({ ok: true }, { status: 201 });
}
```

```typescript
// frontend/src/components/auth/SignupForm.tsx
"use client";

import { useState } from "react";
import { z } from "zod";
import { Input } from "@/components/ui/Input";
import { Button } from "@/components/ui/Button";

const signupFormSchema = z.object({
  companyName: z.string().min(1, "Company name is required").max(255),
  name: z.string().min(1, "Name is required").max(255),
  email: z.string().email("Enter a valid email address"),
  password: z.string().min(8, "Password must be at least 8 characters"),
});

type FormErrors = Partial<Record<keyof z.infer<typeof signupFormSchema>, string>>;

export function SignupForm() {
  const [companyName, setCompanyName] = useState("");
  const [name, setName] = useState("");
  const [email, setEmail] = useState("");
  const [password, setPassword] = useState("");
  const [errors, setErrors] = useState<FormErrors>({});
  const [submitError, setSubmitError] = useState<string | null>(null);
  const [submitted, setSubmitted] = useState(false);
  const [loading, setLoading] = useState(false);

  async function handleSubmit(e: React.FormEvent) {
    e.preventDefault();
    setSubmitError(null);

    const parsed = signupFormSchema.safeParse({ companyName, name, email, password });
    if (!parsed.success) {
      const fieldErrors: FormErrors = {};
      for (const issue of parsed.error.issues) {
        fieldErrors[issue.path[0] as keyof FormErrors] = issue.message;
      }
      setErrors(fieldErrors);
      return;
    }
    setErrors({});
    setLoading(true);

    const res = await fetch("/api/signup", {
      method: "POST",
      headers: { "content-type": "application/json" },
      body: JSON.stringify(parsed.data),
    });

    setLoading(false);
    if (!res.ok) {
      const body = await res.json().catch(() => null);
      setSubmitError(body?.error?.message ?? "Unable to submit your request.");
      return;
    }

    setSubmitted(true);
  }

  if (submitted) {
    return (
      <div role="status" className="text-center">
        <p className="text-sm font-medium text-slate-900">Request submitted</p>
        <p className="mt-2 text-sm text-slate-600">
          Thanks — your access request is pending review. A Super Admin will approve it before you
          can sign in.
        </p>
      </div>
    );
  }

  return (
    <form onSubmit={handleSubmit} noValidate className="flex flex-col gap-4">
      <Input
        label="Company name"
        placeholder="Acme Corp"
        value={companyName}
        onChange={(e) => setCompanyName(e.target.value)}
        error={errors.companyName}
        autoComplete="organization"
        autoFocus
        disabled={loading}
      />
      <Input
        label="Full name"
        placeholder="Jane Smith"
        value={name}
        onChange={(e) => setName(e.target.value)}
        error={errors.name}
        autoComplete="name"
        disabled={loading}
      />
      <Input
        label="Email address"
        type="email"
        placeholder="jane@acme.com"
        value={email}
        onChange={(e) => setEmail(e.target.value)}
        error={errors.email}
        autoComplete="email"
        disabled={loading}
      />
      <Input
        label="Password"
        type="password"
        placeholder="At least 8 characters"
        value={password}
        onChange={(e) => setPassword(e.target.value)}
        error={errors.password}
        autoComplete="new-password"
        disabled={loading}
      />

      {submitError && (
        <div role="alert" className="rounded-lg border border-danger/20 bg-danger-light px-3 py-2">
          <p className="text-xs text-danger-dark">{submitError}</p>
        </div>
      )}

      <Button type="submit" loading={loading} className="mt-1 w-full" size="lg">
        Request access
      </Button>
    </form>
  );
}
```

```typescript
// frontend/src/app/api/admin/users/[id]/signup-status/route.ts
import { NextRequest, NextResponse } from "next/server";
import { getServerSession } from "next-auth";
import { authOptions } from "@/lib/auth";
import { prisma } from "@/lib/prisma";
import { Role, SignupStatus } from "@prisma/client";

interface Params {
  params: Promise<{ id: string }>;
}

export async function PATCH(req: NextRequest, { params }: Params) {
  const session = await getServerSession(authOptions);

  if (!session?.user?.id) {
    return NextResponse.json(
      { error: { code: "UNAUTHORIZED", message: "Unauthorized" } },
      { status: 401 }
    );
  }
  if (session.user.role !== Role.SUPER_ADMIN) {
    return NextResponse.json(
      { error: { code: "FORBIDDEN", message: "Only a Super Admin can review access requests." } },
      { status: 403 }
    );
  }

  const { id } = await params;
  const body = await req.json().catch(() => null);
  const signupStatus = body?.signupStatus;
  if (signupStatus !== SignupStatus.APPROVED && signupStatus !== SignupStatus.REJECTED) {
    return NextResponse.json(
      { error: { code: "INVALID_STATUS", message: "signupStatus must be APPROVED or REJECTED." } },
      { status: 400 }
    );
  }

  const target = await prisma.user.findUnique({ where: { id } });
  if (!target) {
    return NextResponse.json(
      { error: { code: "NOT_FOUND", message: "User not found." } },
      { status: 404 }
    );
  }

  const updated = await prisma.user.update({
    where: { id },
    data: { signupStatus },
    select: { id: true, email: true, name: true, companyName: true, role: true, signupStatus: true },
  });

  return NextResponse.json({ user: updated });
}
```

```typescript
// frontend/src/components/admin/SignupRequestRow.tsx
"use client";

import { useRouter } from "next/navigation";
import { Check, X } from "lucide-react";
import { Badge } from "@/components/ui/Badge";
import { Button } from "@/components/ui/Button";

interface SignupRequestRowProps {
  userId: string;
  companyName: string | null;
  name: string;
  email: string;
  signupStatus: "PENDING" | "REJECTED";
  requestedAt: string;
}

export function SignupRequestRow({
  userId,
  companyName,
  name,
  email,
  signupStatus,
  requestedAt,
}: SignupRequestRowProps) {
  const router = useRouter();
  const [saving, setSaving] = useState(false);
  const [error, setError] = useState<string | null>(null);

  async function setStatus(nextStatus: "APPROVED" | "REJECTED") {
    setSaving(true);
    setError(null);
    try {
      const res = await fetch(`/api/admin/users/${userId}/signup-status`, {

      if (!res.ok) {

        setError(body?.error?.message ?? "Failed to update request.");
        return;
      }
      router.refresh();
    } catch {
      setError("Network error — please try again.");
    } finally {
      setSaving(false);
    }
  }

  return (
    <div className="flex items-center gap-4 px-5 py-4">
      <div className="min-w-0 flex-1">
        <div className="flex flex-wrap items-center gap-2">
          <p className="truncate text-sm font-medium text-slate-900">

          <Badge variant={signupStatus === "REJECTED" ? "red" : "yellow"}>

          </Badge>
        </div>
        <p className="mt-0.5 truncate text-xs text-slate-500">
          {name} — {email}
        </p>
        <p className="mt-0.5 text-xs text-slate-400">Requested {requestedAt}</p>
        {error && <p className="mt-1 text-xs text-danger">{error}</p>}
      </div>

          variant="secondary"
          disabled={saving}

          onClick={() => setStatus("REJECTED")}
        >
          Reject
        </Button>
        <Button
          size="sm"
          disabled={saving}
          leftIcon={<Check className="h-3.5 w-3.5" />}
          onClick={() => setStatus("APPROVED")}
        >
          Approve
        </Button>
      </div>
    </div>
```
