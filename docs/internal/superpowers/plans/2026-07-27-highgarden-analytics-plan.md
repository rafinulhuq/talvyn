# HighGarden Analytics Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build HighGarden — an in-house, Hotjar-style click/pageview tracking system inside the superadmin panel, gated behind a second passphrase separate from normal login.

**Architecture:** Entirely inside the existing Next.js frontend (App Router + Prisma), following the codebase's existing patterns exactly: API routes write straight to Postgres via the shared `prisma` client (same pattern as `frontend/src/app/api/admin/*` and `frontend/src/app/api/observability/web-vitals/route.ts`); dashboard pages are async server components that query `prisma` directly and re-check auth themselves (same pattern as `frontend/src/app/(admin)/dashboard/users/page.tsx`). No changes to the separate FastAPI backend.

**Tech Stack:** Next.js 16 (App Router), Prisma 6 / PostgreSQL, NextAuth (JWT sessions), `bcryptjs` (already a dependency), `recharts` (already a dependency), Playwright (`tests/e2e`) for testing — this repo has no unit-test runner (jest/vitest) configured, only Playwright e2e, so all tests below use that.

## Global Constraints

- v1 tracks only page views and clicks. No visual heatmap overlay, no session replay, no funnels — do not add `x`/`y` coordinates, DOM snapshots, or video capture.
- Tracking covers the **entire site**, including the admin dashboard itself. Do not add any "skip tracking for logged-in staff" logic.
- The HighGarden passphrase is **one shared secret** (bcrypt hash in an env var), not per-superadmin. Do not add a per-user passphrase table.
- Raw events are retained 90 days, purged via a **manual** admin-triggered action. Do not add cron/scheduler infrastructure — none exists in this repo.
- Every new DB-writing/reading route must reuse the existing `prisma` singleton from `@/lib/prisma`; never instantiate a second `PrismaClient`.
- Every protected HighGarden page must re-check access itself (session role + unlock cookie), not rely solely on the sidebar hiding its nav link — this mirrors the existing `UsersPage` comment: "the URL itself is guessable — re-check here rather than relying on nav visibility as the only access control."
- This repo has no seeded test admin / storage-state fixture for e2e yet (see `frontend/tests/e2e/README.md`'s "Next Coverage To Add"). Do not invent one as part of this plan — where a test would require a logged-in `SUPER_ADMIN` browser session, write the test for the reachable unauthenticated/unauthorized path instead, and say so in the task rather than skipping the test silently.

```typescript
// frontend/src/app/api/track/route.ts
import { NextRequest, NextResponse } from "next/server";
import { z } from "zod";
import { prisma } from "@/lib/prisma";
import { TrackedEventType } from "@prisma/client";

const trackSchema = z.object({
  sessionId: z.string().min(1).max(100),
  type: z.nativeEnum(TrackedEventType),
  path: z.string().min(1).max(500),
  targetLabel: z.string().max(200).optional(),
  targetSelector: z.string().max(200).optional(),
});

export async function POST(req: NextRequest) {
  const body = await req.json().catch(() => null);
  const parsed = trackSchema.safeParse(body);

  // Never surface ingestion errors to real visitors — a blocked/broken
  // beacon must never affect the page they're actually using.
  if (!parsed.success) {
    return new NextResponse(null, { status: 204 });
  }

  const { sessionId, type, path, targetLabel, targetSelector } = parsed.data;

  await prisma.visitorSession.upsert({
    where: { id: sessionId },
    create: { id: sessionId },
    update: { lastSeenAt: new Date() },
  });

  await prisma.trackedEvent.create({
    data: { sessionId, type, path, targetLabel, targetSelector },
  });

  return new NextResponse(null, { status: 204 });
}
```

```typescript
// frontend/src/components/tracking/HighGardenTracker.tsx
"use client";

import { useEffect } from "react";
import { usePathname } from "next/navigation";

const SESSION_COOKIE = "hg_sid";
const SESSION_MAX_AGE_SECONDS = 365 * 24 * 60 * 60;

function getOrCreateSessionId(): string {
  const match = document.cookie.match(new RegExp(`(?:^|; )${SESSION_COOKIE}=([^;]+)`));
  if (match) return decodeURIComponent(match[1]);

  const id = crypto.randomUUID();
  document.cookie = `${SESSION_COOKIE}=${encodeURIComponent(id)}; path=/; max-age=${SESSION_MAX_AGE_SECONDS}; samesite=lax`;
  return id;
}

function send(payload: Record<string, unknown>) {
  const body = new Blob([JSON.stringify(payload)], { type: "application/json" });
  if (!navigator.sendBeacon("/api/track", body)) {
    // sendBeacon returns false if the payload couldn't be queued (rare) —
    // fall back to a best-effort fetch rather than losing the event.
    void fetch("/api/track", {
      method: "POST",
      headers: { "content-type": "application/json" },
      body: JSON.stringify(payload),
      keepalive: true,
    });
  }
}

function describeTarget(el: Element): { label: string; selector: string } {
  const label = (el.textContent ?? "").trim().slice(0, 200) || el.getAttribute("aria-label") || "";
  const selector = el.id
    ? `#${el.id}`
    : `${el.tagName.toLowerCase()}${el.className ? "." + el.className.toString().trim().split(/\s+/).join(".") : ""}`;
  return { label, selector: selector.slice(0, 200) };
}

export function HighGardenTracker() {
  const pathname = usePathname();

  useEffect(() => {
    const sessionId = getOrCreateSessionId();
    send({ sessionId, type: "PAGE_VIEW", path: pathname });
  }, [pathname]);

  useEffect(() => {
    function onClick(event: MouseEvent) {
      const target = (event.target as Element | null)?.closest(
        "button, a, [role='button']"
      );
      if (!target) return;

      const sessionId = getOrCreateSessionId();
      const { label, selector } = describeTarget(target);
      send({
        sessionId,
        type: "CLICK",
        path: window.location.pathname,
        targetLabel: label,
        targetSelector: selector,
      });
    }

    document.addEventListener("click", onClick, { capture: true });
    return () => document.removeEventListener("click", onClick, { capture: true });
  }, []);

  return null;
}
```

```typescript
// frontend/src/lib/highgarden/unlockCookie.ts
import { createHmac, timingSafeEqual } from "node:crypto";

export const HIGHGARDEN_UNLOCK_COOKIE = "hg_unlocked";

const TTL_MS = 4 * 60 * 60 * 1000; // 4 hours

function sign(expiresAt: number): string {
  const secret = process.env.NEXTAUTH_SECRET ?? "";
  return createHmac("sha256", secret).update(String(expiresAt)).digest("hex");
}

export function createUnlockCookieValue(): { value: string; maxAge: number } {
  const expiresAt = Date.now() + TTL_MS;
  return { value: `${expiresAt}.${sign(expiresAt)}`, maxAge: TTL_MS / 1000 };
}

export function isUnlockCookieValid(value: string | undefined): boolean {
  if (!value) return false;

  const [expiresAtRaw, signature] = value.split(".");
  if (!expiresAtRaw || !signature) return false;

  const expiresAt = Number(expiresAtRaw);
  if (Number.isNaN(expiresAt) || Date.now() > expiresAt) return false;

  const expected = Buffer.from(sign(expiresAt));
  const actual = Buffer.from(signature);
  return expected.length === actual.length && timingSafeEqual(expected, actual);
}
```

```typescript
// frontend/src/app/api/highgarden/unlock/route.ts
import { NextRequest, NextResponse } from "next/server";
import { getServerSession } from "next-auth";
import bcrypt from "bcryptjs";
import { z } from "zod";
import { authOptions } from "@/lib/auth";
import { Role } from "@prisma/client";
import { createUnlockCookieValue, HIGHGARDEN_UNLOCK_COOKIE } from "@/lib/highgarden/unlockCookie";

const unlockSchema = z.object({
  passphrase: z.string().min(1),
});

export async function POST(req: NextRequest) {
  const session = await getServerSession(authOptions);
  if (session?.user?.role !== Role.SUPER_ADMIN) {
    return NextResponse.json(
      { error: { code: "FORBIDDEN", message: "Super Admin access required." } },
      { status: 403 }
    );
  }

  const configuredHash = process.env.HIGHGARDEN_PASSPHRASE_HASH;
  if (!configuredHash) {
    return NextResponse.json(
      { error: { code: "NOT_CONFIGURED", message: "HighGarden is not configured on this environment." } },
      { status: 503 }
    );
  }

  const body = await req.json().catch(() => null);
  const parsed = unlockSchema.safeParse(body);
  if (!parsed.success) {
    return NextResponse.json(
      { error: { code: "VALIDATION_ERROR", message: "Passphrase is required." } },
      { status: 400 }
    );
  }

  const valid = await bcrypt.compare(parsed.data.passphrase, configuredHash);
  if (!valid) {
    return NextResponse.json(
      { error: { code: "INVALID_PASSPHRASE", message: "Incorrect passphrase." } },
      { status: 401 }
    );
  }

  const { value, maxAge } = createUnlockCookieValue();
  const response = NextResponse.json({ ok: true });
  response.cookies.set(HIGHGARDEN_UNLOCK_COOKIE, value, {
    httpOnly: true,
    secure: process.env.NODE_ENV === "production",
    sameSite: "lax",
    path: "/",
    maxAge,
  });
  return response;
}
```

```typescript
import { getServerSession } from "next-auth";
import { Role } from "@prisma/client";
import { authOptions } from "@/lib/auth";
import { HIGHGARDEN_UNLOCK_COOKIE, isUnlockCookieValid } from "@/lib/highgarden/unlockCookie";

/** Redirects away and never returns unless the caller is a Super Admin with
 * an active HighGarden unlock cookie. Every protected HighGarden page must
 * call this first — the unlock page itself must NOT call this (it would
 * redirect to itself in a loop); see requireSuperAdminOnly below. */
export async function requireHighGardenAccess(): Promise<void> {
  const role = await requireSuperAdminOnly();
  void role;

  const cookieStore = await cookies();
  if (!isUnlockCookieValid(cookieStore.get(HIGHGARDEN_UNLOCK_COOKIE)?.value)) {
    redirect("/dashboard/highgarden/unlock");
  }
}

/** Used only by the unlock page: checks the Super Admin role but not the
 * unlock cookie (checking the cookie there would redirect a not-yet-unlocked
 * Super Admin back to the very page they're on). */
export async function requireSuperAdminOnly(): Promise<void> {
  const session = await getServerSession(authOptions);
  if (session?.user?.role !== Role.SUPER_ADMIN) {
    redirect("/dashboard");
  }
}
```

```typescript
      method: "POST",
      headers: { "content-type": "application/json" },

      const body = await res.json().catch(() => null);
      setError(body?.error?.message ?? "Unable to unlock HighGarden.");
      return;
    }

    router.push("/dashboard/highgarden");
    router.refresh();
  }
```

```typescript
// frontend/src/app/(admin)/dashboard/highgarden/page.tsx
import type { Metadata } from "next";
import Link from "next/link";
import { prisma } from "@/lib/prisma";
import { requireHighGardenAccess } from "@/lib/highgarden/requireAccess";
import { PageHeader } from "@/components/ui/PageHeader";
import { EventTrendChart } from "@/components/highgarden/EventTrendChart";

export const metadata: Metadata = { title: "HighGarden" };
export const revalidate = 0;

const RANGE_DAYS = new Set([7, 30, 90]);

function sinceFromRange(range: number): Date {
  return new Date(Date.now() - range * 24 * 60 * 60 * 1000);
}

export default async function HighGardenPage({
  searchParams,
}: {
  searchParams: Promise<{ range?: string; path?: string }>;
}) {
  await requireHighGardenAccess();

  const params = await searchParams;
  const range = RANGE_DAYS.has(Number(params.range)) ? Number(params.range) : 30;
  const since = sinceFromRange(range);
  const filterPath = params.path;

  const [pageViewCount, clickCount] = await Promise.all([
    prisma.trackedEvent.count({ where: { type: "PAGE_VIEW", createdAt: { gte: since } } }),
    prisma.trackedEvent.count({ where: { type: "CLICK", createdAt: { gte: since } } }),
  ]);

  const trend = await prisma.$queryRaw<Array<{ day: Date; count: bigint }>>`
    SELECT date_trunc('day', "createdAt") AS day, COUNT(*) AS count
    FROM "TrackedEvent"
    WHERE "createdAt" >= ${since}
    GROUP BY day
    ORDER BY day ASC
  `;
  const trendData = trend.map((row) => ({
    day: row.day.toISOString().slice(0, 10),
    count: Number(row.count),
  }));

  const elementBreakdown = filterPath
    ? await prisma.trackedEvent.groupBy({
        by: ["targetLabel"],
        where: { type: "CLICK", path: filterPath, createdAt: { gte: since }, targetLabel: { not: null } },
        _count: { _all: true },
        orderBy: { _count: { _all: "desc" } },
        take: 10,
      })
    : [];

  const topPages = !filterPath
    ? await prisma.trackedEvent.groupBy({
        by: ["path"],
        where: { type: "PAGE_VIEW", createdAt: { gte: since } },
        _count: { _all: true },
        orderBy: { _count: { _all: "desc" } },
        take: 10,
      })
    : [];

  const topElements = !filterPath
    ? await prisma.trackedEvent.groupBy({
        by: ["path", "targetLabel"],
        where: { type: "CLICK", createdAt: { gte: since }, targetLabel: { not: null } },
        _count: { _all: true },
        orderBy: { _count: { _all: "desc" } },
        take: 10,
      })
    : [];

  return (
    <div className="mx-auto max-w-5xl">
      <PageHeader
        title="HighGarden"
        subtitle="Site-wide click and page-view analytics."
        className="mb-8"
      />

      <div className="mb-6 flex gap-2">
        {[7, 30, 90].map((r) => (
          <Link
            key={r}
            href={`/dashboard/highgarden?range=${r}${filterPath ? `&path=${encodeURIComponent(filterPath)}` : ""}`}
            className={`rounded-lg px-3 py-1.5 text-sm ${
              r === range ? "bg-brand-600 text-white" : "bg-slate-100 text-slate-700"
            }`}
          >
            {r}d
          </Link>
        ))}
      </div>

      <div className="mb-6 grid grid-cols-2 gap-4">
        <div className="card p-4">
          <p className="text-xs text-slate-500">Page views ({range}d)</p>
          <p className="text-2xl font-semibold">{pageViewCount}</p>
        </div>
        <div className="card p-4">
          <p className="text-xs text-slate-500">Clicks ({range}d)</p>
          <p className="text-2xl font-semibold">{clickCount}</p>
        </div>
      </div>

      <div className="card mb-6 p-4">
        <EventTrendChart data={trendData} />
      </div>

      {filterPath ? (
        <div className="card p-4">
          <div className="mb-3 flex items-center justify-between">
            <h2 className="text-sm font-semibold">Clicks on {filterPath}</h2>
            <Link href={`/dashboard/highgarden?range=${range}`} className="text-xs text-brand-600">
              Back to overview
            </Link>
          </div>
          <ul className="flex flex-col gap-1 text-sm">
            {elementBreakdown.map((row) => (
              <li key={row.targetLabel} className="flex justify-between">
                <span>{row.targetLabel}</span>
                <span className="text-slate-500">{row._count._all}</span>
              </li>
            ))}
          </ul>
        </div>
      ) : (
        <div className="grid grid-cols-2 gap-4">
          <div className="card p-4">
            <h2 className="mb-3 text-sm font-semibold">Top pages</h2>
            <ul className="flex flex-col gap-1 text-sm">
              {topPages.map((row) => (
                <li key={row.path} className="flex justify-between">
                  <Link
                    href={`/dashboard/highgarden?range=${range}&path=${encodeURIComponent(row.path)}`}
                    className="truncate text-brand-600 hover:underline"
                  >
                    {row.path}
                  </Link>
                  <span className="text-slate-500">{row._count._all}</span>
                </li>
              ))}
            </ul>
          </div>
          <div className="card p-4">
            <h2 className="mb-3 text-sm font-semibold">Top clicked elements</h2>
            <ul className="flex flex-col gap-1 text-sm">
              {topElements.map((row) => (
                <li key={`${row.path}-${row.targetLabel}`} className="flex justify-between gap-2">
                  <span className="truncate">
                    {row.targetLabel} <span className="text-slate-400">({row.path})</span>
                  </span>
                  <span className="shrink-0 text-slate-500">{row._count._all}</span>
                </li>
              ))}
            </ul>
          </div>
        </div>
      )}
    </div>
  );
}
```

```typescript
// frontend/src/app/api/highgarden/purge/route.ts
import { NextResponse } from "next/server";
import { cookies } from "next/headers";
import { getServerSession } from "next-auth";
import { authOptions } from "@/lib/auth";
import { Role } from "@prisma/client";
import { prisma } from "@/lib/prisma";
import { HIGHGARDEN_UNLOCK_COOKIE, isUnlockCookieValid } from "@/lib/highgarden/unlockCookie";

const RETENTION_MS = 90 * 24 * 60 * 60 * 1000;

export async function POST() {
  const session = await getServerSession(authOptions);
  if (session?.user?.role !== Role.SUPER_ADMIN) {
    return NextResponse.json(
      { error: { code: "FORBIDDEN", message: "Super Admin access required." } },
      { status: 403 }
    );
  }

  const cookieStore = await cookies();
  if (!isUnlockCookieValid(cookieStore.get(HIGHGARDEN_UNLOCK_COOKIE)?.value)) {
    return NextResponse.json(
      { error: { code: "LOCKED", message: "HighGarden is locked." } },
      { status: 403 }
    );
  }

  const cutoff = new Date(Date.now() - RETENTION_MS);
  const { count: deletedEvents } = await prisma.trackedEvent.deleteMany({
    where: { createdAt: { lt: cutoff } },
  });
  const { count: deletedSessions } = await prisma.visitorSession.deleteMany({
    where: { events: { none: {} } },
  });

  return NextResponse.json({ deletedEvents, deletedSessions });
}
```

```typescript
// frontend/src/components/highgarden/PurgeButton.tsx
"use client";

import { useState } from "react";
import { useRouter } from "next/navigation";

export function PurgeButton() {
  const router = useRouter();
  const [pending, setPending] = useState(false);
  const [result, setResult] = useState<string | null>(null);

  async function handleClick() {
    if (!confirm("Permanently delete tracked events older than 90 days?")) return;

    setPending(true);
    const res = await fetch("/api/highgarden/purge", { method: "POST" });
    const body = await res.json().catch(() => null);
    setPending(false);

    if (!res.ok) {
      setResult(body?.error?.message ?? "Purge failed.");
      return;
    }

    setResult(`Deleted ${body.deletedEvents} events and ${body.deletedSessions} empty sessions.`);
    router.refresh();
  }

  return (
    <div className="flex items-center gap-3">
      <button
        onClick={handleClick}
        disabled={pending}
        className="rounded-lg border border-slate-300 px-3 py-1.5 text-xs font-medium text-slate-700 hover:bg-slate-50 disabled:opacity-50"
      >
        {pending ? "Purging…" : "Purge events older than 90 days"}
      </button>
      {result && <span className="text-xs text-slate-500">{result}</span>}
    </div>
  );
}
```

## V2 Expansion Plan — Superadmin Product Insights

> Added 2026-08-06 after v1 implementation. Treat this as the next HighGarden backlog, not as part of the original v1 scope. Keep every feature **SUPER_ADMIN-only** and behind the existing HighGarden unlock gate.

**Goal:** Upgrade HighGarden from basic page/click analytics into a self-hosted product-experience console for the superadmin: understand where users/candidates struggle, which workflows are failing, and what should be improved next.

**Guardrails:**
- Do not expose HighGarden to `USER` or `ADMIN`; navigation, pages, API routes, and server actions must all re-check `SUPER_ADMIN`.
- Preserve ownership/data-scoping for normal app data. HighGarden can observe all site events, but it must not become a shortcut for editing non-analytics resources.
- Avoid collecting passwords, tokens, form field contents, candidate answers, phone numbers, emails from input values, or raw document text. Analytics may record page paths, element labels, selectors, timing, viewport/device metadata, and coarse workflow status.
- Keep capture lightweight. If a feature would noticeably slow candidate exams or admin workflows, batch/throttle it or defer it.
- Prefer aggregated summaries first, then drill-down detail. Superadmin should get answers quickly, not just an event firehose.
